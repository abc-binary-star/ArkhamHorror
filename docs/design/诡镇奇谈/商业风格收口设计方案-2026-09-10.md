# 诡镇奇谈 · 商业风格收口设计方案

版本：1.0 · 2026-09-10  
目标：在现有「深海档案馆」方向上完成最后一轮组件收口，使首页、工作台、牌桌和剧情交互都达到克苏鲁商业桌游产品的统一质感。

## 1. 结论与设计目标

现有视觉方向已经成立：深海石板、象牙档案纸、氧化黄铜和低对比雾面材质形成了清晰品牌识别。本轮不改变品牌方向，也不增加持续性的触手、血迹、眼睛或霓虹效果，而是解决“页面像同一作品、组件却像不同系统”的问题。

本轮完成标准：

1. 主要页面共享同一套纸面、边线、按钮、焦点和状态语言。
2. 交互组件具有实体感，但文字和规则信息仍由 HTML 渲染，保证可读性与本地化。
3. 氛围集中在封面、牌桌边缘和弹窗外框；操作区保持安静、明亮、可读。
4. 选中、悬浮、拖拽、禁用、加载、错误、等待和危险状态一眼可区分。
5. 桌面与移动端保持同一品牌，但采用不同构图，不强行裁切桌面素材。

## 2. 视觉基线

### 2.1 色彩比例

| 层级 | 颜色 | 建议占比 | 用途 |
| --- | --- | ---: | --- |
| 结构底色 | 深海 `#26373A`、牌桌灰 `#626E70` | 45% | 导航、牌桌、边缘和深色容器 |
| 阅读表面 | 象牙纸 `#E8E1D2`、亮纸 `#F4EFE4` | 40% | 面板、日志、弹窗和编辑区 |
| 品牌细节 | 黄铜 `#9B7D45`、亮黄铜 `#C8AD78` | 8% | 细边线、角饰、选中和编号 |
| 功能语义 | 青绿、氧化红、少量神秘紫 | 7% | 可操作、危险、神秘事件和职业语义 |

紫色只保留给神秘事件或特定职业语义，不再作为通用按钮和全局选中态。通用选中态改为“黄铜边线 + 内部刻度 + 文本提示”，不依赖单一颜色。

### 2.2 材质规则

- 纸面必须有真实边界、轻纤维和接触阴影；不能只靠半透明黑盒。
- 黄铜只做 1px 结构线、角饰、印记和交互高光，不做大面积金色填充。
- 牌桌中央保持中明度和低纹理，确保卡牌信息优先。
- 圆角统一为 3–6px；卡牌和纸张不使用气泡式 12–16px 圆角。
- 动效只表达“翻页、落桌、揭示”三种动作；持续脉冲仅用于阻塞性危险状态。

## 3. 页面与组件收口

### 3.1 首页与公共壳层

首页继续作为“海港案件档案封面”：Hero 承担叙事，档案列表承担功能。登录、注册、关于和设置页面沿用档案纸，但减少空白区域，增加案件编号、细黄铜分隔线和统一页眉，让公共页面不再像普通后台。

### 3.2 工作台与卡牌库

牌组编辑和卡牌库统一使用“调查员工作台”：

- 顶部工具条使用深海底板 + 黄铜刻度，不使用连续彩色胶囊。
- 卡槽采用浅纸底、内凹线和编号；空槽显示卡背纹章，不显示空白灰框。
- 默认卡牌不发光；悬浮只抬升 2px；选中使用黄铜双线和“已选择”文本。
- 拖拽显示窄黄铜插入线和纸张占位，不使用紫色粗边框。
- 加载、无结果和移出状态使用档案纸牌，保持尺寸与卡牌比例一致。

### 3.3 牌桌与 HUD

牌桌采用“石板桌面 + 档案抽屉 + 实体行动托盘”的三层关系：

1. 中央地图只承载地点、敌人、调查员和卡牌。
2. 侧栏是可覆盖的档案抽屉，打开后不压缩主要地图。
3. 底部行动区是固定高度的纸面托盘，按钮像压在托盘上的铭牌。

当前行动使用黄铜边框和小型档案标签；等待使用静态纸签；危险使用氧化红印章。禁止让整张牌桌持续闪烁或使用大面积霓虹光。

### 3.4 剧情、检定与确认弹窗

所有弹窗统一为“外层深海遮罩 + 纸面外框 + 细黄铜内线 + 内容安全区”：

- 标题区使用宋体和案件编号；
- 正文使用高对比亮纸，不放在半透明黑底上；
- 选择按钮统一为窄边纸牌按钮，主要操作使用深海青绿，危险操作使用氧化红；
- 选中态使用黄铜内线和勾选／文字，不用洋红色发光；
- 长正文可滚动，但标题与底部确认区保持可见；
- `prefers-reduced-motion` 下保留状态变化，只取消滑入、脉冲和旋转。

所有素材均不包含文字、Logo、具体卡牌规则或按钮文案；文字由 HTML 叠加。素材保存为 PNG，优先作为背景或遮罩使用，后续可再导出 WebP。

## 5. 实施顺序

### P0：统一交互语言

1. 抽取 `ActionButton`、`PaperModalFrame`、`ArchiveDrawer` 和 `CardInteractionState` 的共享样式。
2. 清理 `Question.vue`、`StoryQuestion.vue`、`ChoiceModal.vue` 中覆盖全局按钮的旧紫色、Arial、过大圆角规则。
3. 将选中态从通用洋红改为黄铜结构态；神秘紫仅保留在明确的神秘事件语义。

### P1：接入本轮素材

1. 先接入弹窗内框、行动按钮铭牌和行动托盘。
2. 再接入档案抽屉、卡牌状态带和状态印章组。
3. 统一桌面、窄屏和移动端的安全区与层级。

### P1：视觉验收

使用 1440×900、1280×720、1024×768、390×844 四组视口检查：首页、牌组、卡牌库、新战役、牌桌、弹窗、错误、等待和空状态。另检查键盘焦点、125% 缩放、长中文文案、`prefers-reduced-motion` 与低高度窗口。

## 6. 验收门槛

- 任意主要页面不再出现与主题冲突的默认紫色通用按钮。
- 主要弹窗只出现一套纸面结构，标题、正文、选择区和危险区层级明确。
- 卡牌默认／悬浮／选中／拖拽／禁用／加载状态无需解释即可区分。
- 牌桌 HUD 不遮挡卡牌数字、地点名称和主要行动按钮。
- 移动端采用独立构图，侧栏以覆盖抽屉呈现，底部操作区不被安全区遮挡。
- 资产为无文字底图，中文、本地化和辅助功能信息均由 DOM 提供。
