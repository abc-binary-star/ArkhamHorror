# 诡镇奇谈 · 牌桌专项设计方案

依据：用户提供的 2932×1490 实机截图。日期：2026-09-09。交付范围：设计与素材，不修改应用代码，不复制新图到运行时目录。

## 1. 判断与纠偏

这张截图没有达到精致商业作品的标准。此前依据资源引用数量给出的 6.5–7 分缺少实机依据，本次不沿用该评分。素材已接入，不等于视觉设计已经完成。

核心问题是空间组织、层级和材质使用方式。继续给每个控件加金属框，会让界面更繁杂。应把牌桌作为一个完整场景设计，以真实卡牌为视觉主角。

| 截图中的现象 | 对游玩的影响 | 本次设计决策 |
| --- | --- | --- |
| 地图、装备区和手牌区都是接近的平灰色 | 前后层级消失，长时间观看乏味 | 地图用暗青织物，玩家区用墨绿皮革，纸张只用于阅读 |
| 顶部白色场景带占用大量高度，卡牌散在中央 | 压缩地图空间，信息没有分组 | 场景卡带紧凑靠左，右侧显示当前阶段与进度 |
| 粗白虚线连接地点 | 连线比卡牌更抢眼 | 细黄铜实线，连接至卡边，路径高亮仅在相关操作时出现 |
| 空装备槽又大又亮，数量多于实际装备 | 空状态成为主角 | 用紧凑槽位摘要；装备时才展开对应完整槽位 |
| 调查员、牌库、手牌和结束回合分散 | 视线频繁跨越空白寻找操作 | 调查员、手牌、行动形成连续的下部工作区 |
| 日志一条一盒，字号粗大，独立竖向阶段轨很宽 | 日志比地图更显眼，重复边框增加噪声 | 书页式段落日志，阶段标题归入正文分组 |
| 顶部金属素材被压成细条，按钮文字被装饰干扰 | 显得像贴图拼装，文字不清楚 | 普通导航用纯色与细线；仅主行动保留轻量材质 |
| 日志中存在中英文混排和长英文专名 | 排版不稳定 | 长词换行、正文正常字重、人物名局部强调；翻译另列内容任务 |

## 2. 美术方向：深夜调查室

正式名称始终为「诡镇奇谈」。城市、档案与未知威胁共同构成氛围，港口只可作为某个剧本的场景，不能成为全游戏的新品牌。

视觉层次依次为：卡牌与当前选择 → 行动及资源 → 地图关系 → 场景进度 → 日志 → 装饰。材质只承担区域区分，不承担点击状态或规则含义。

色板建议：地图底色 #172C2B，深部 #101C1D，皮革 #202720，明文 #E7E0D1，纸面 #DCD6C8，纸上正文 #30352F，黄铜 #9B8758，危险 #A65045。颜色是设计起点，实际文字对比须验收，不能用色板数值代替验收。

标题采用有完整中文覆盖的宋体／衬线体；正文用清楚的黑体；数字使用等宽数字。正文 14–16px、行高 1.5–1.65；工具栏 13–14px；章节标题 18–22px。所有字号为 CSS 像素，与截图物理像素分开。

## 3. 桌面布局规格

以 1440×900 CSS 视口为设计基准。顶部品牌工具栏 44px，场景区约 104px，底部玩家区约 300px，中部地图分配剩余空间。分界允许拖动，并提供恢复默认；不把比例永久锁死。

```text

│ 遭遇牌库 / 密谋 / 场景卡             第3轮 · 调查阶段      │
├─────────────────────────────────────┬───────────────┤
│                                     │ 日志  ·  未读  │
│       地点卡与细线连接的调查地图      │ 阶段标题       │
│       当前地点有柔和光晕与指示        │ 紧凑记录       │
│                                     │ 可收起         │
├ 调查员标签 ─────────────────────────┴───────────────┤
│ 调查员档案 │ 已装备资产 / 威胁区             槽位摘要      │

│ 资源计数   │ 当前选择提示                   结束回合      │
```

日志默认折叠，右缘显示“日志 + 未读数”。宽屏用户可固定展开，宽 280–320px、最多占视口 22%；主地图宽度不足 900px 时变覆盖抽屉。保留用户选择。高危规则提示进入行动提示区，不能只写入折叠日志。

地图和手牌各自缩放，避免放大地图时手牌同时爆出屏幕。保留缩放按钮与适应全图，减少长期占据标签栏的滑杆和锁定图标。

## 4. 地图区

- T01 是地图容器的背景。中心为安静区域；外围街道纹理仅作气氛，不代表可走的实际道路。实际地点关系必须由规则连线表达。
- 五地点场景先自动适应可用范围，再允许平移缩放。参考卡牌尺寸 100–120px 宽、140–168px 高，保持真实卡面比例；不能为了铺满屏幕把地点拉得很散。
- 连线 1–1.5px，默认低对比黄铜色；可移动路径升至 2px，使用端点与箭头表达方向；封闭路径用断口或锁符号，不只换颜色。
- 当前地点增加柔和局部光和细边框；可选地点加明确标签／焦点环。选中、可选、敌人威胁用不同形状和标识，不靠满屏发光。
- 调查员头像停靠卡边外侧，人数多时成组展开；敌人放在地点邻近威胁区，不能挡住名称和标记。
- 卡牌详情由悬停或点击打开清晰阅读视图，地图缩略卡不承担全文阅读。

## 5. 调查员、装备与手牌

T02 作为玩家区统一底材。调查员档案宽约 220px；属性为四项小型数字与原有游戏图标，职业色仅作窄条。生命与理智必须保留当前业务含义，例如显示的是伤害／恐惧时，不能改文案为剩余生命／理智。

装备区优先显示已装备卡，普通空槽折成 24–28px 的小图标与剩余数。需要装备时展开相关可选槽；特殊槽、占用多个槽、封锁槽均保留原有语义。无需为每个空槽准备一张高细节图片。

手牌基准高 145–170px，四张牌居中排列，间距 8–12px；多牌可轻微重叠，但名称与点击区域保持可辨认。悬停只上移 8px 并置顶，不能遮住主行动。触摸端点击先预览，再明确选择。牌库与弃牌堆贴近手牌左侧并显示数量。

手牌上限以“手牌 4 / 8”的小型注释展示，移除整条高饱和绿条。超限时添加警示图标、文案和边线，其他状态保持安静。

## 6. 行动与状态语言

真正的回合操作位于玩家区右下，宽约 180px；顶部 game-bar 是全局工具栏，不能把它误称为底部回合栏。主要按钮高 44px，允许两行；同一区域只突出一个主要动作。结束回合的二次确认维持现有规则，并将按钮文案与危险提示同时更新。

| 状态 | 视觉处理 |
| --- | --- |
| 默认 | 哑光纸面或暗色实底，细边线 |
| 悬停 | 边线略亮，轻微明度变化 |
| 键盘焦点 | 清晰外轮廓，与悬停区别明显 |
| 按下 | 1px 下沉及内阴影 |
| 禁用 | 降低饱和度，文案仍可读；提供原因 |
| 处理中 | 固定按钮尺寸，显示等待与状态文本，避免连续提交 |
| 危险确认 | 暗红细边与确认文案，无持续闪烁 |

资源图标保留游戏约定，统一圆盘尺寸与数字位置。旧第28张的复杂六徽章不能直接在所有 PoolItem 后面泛用，卡牌堆、线索和伤害等不同类型需要明确映射，不能用装饰造成规则误读。

## 7. 日志和阶段

T03 用于日志抽屉的阅读底材。取消每条记录独立的厚框、圆角与阴影。按轮次／阶段分组，时间为弱化小字，人物名加适量字重；普通正文正常字重。当前最新记录只留左侧 2px 强调线。

用户阅读历史时不强制滚回底部；新记录到达显示“新增 N 条”。加载旧记录保留滚动位置。阶段轨并入日志分组标题与顶部阶段摘要，历史跳转作为可展开目录。

## 9. 响应式和动效

1920×1080：允许固定日志和较宽资产区。1440×900：采用上述基准。1366×768：场景带约 88px、玩家区约 270px，日志默认收起，保证地图能定位所有地点。所有尺寸为可验收的目标，不替代实机测量。

小于 1100px：日志覆盖展开，玩家档案紧凑，装备区和手牌保持分组。手机竖屏：地图为主视图，底部切换“手牌／资产／调查员”，行动固定可达；日志覆盖页。手机横屏：紧凑场景摘要，玩家区可展开。不把桌面所有卡牌缩小塞入手机。

所有转场 120–180ms；不做持续漂雾、无限发光或卡牌晃动。减少动效模式取消位移和非必要动画。触控目标至少 44px；200% 缩放可换行并保持操作可达。

## 10. 后续实施及验收

顺序：先改地图／玩家／日志区域关系 → 统一材质 → 处理连线与空槽 → 收紧调查员与行动 → 检查交互状态。不得先贴素材再宣称商业完成。

验收需实机截图：同一五地点场景，分别记录日志开／关；另测大量地点、多人同地点、十张手牌、多敌人、伤害分配、结束回合确认、等待与断线。对照 1920×1080、1440×900、1366×768 和手机横竖屏。

通过标准：名称和计数无遮挡；地图路径清楚；空槽不抢眼；主行动无需寻找；长日志可读；键盘焦点可见；无材质拉伸和图集串帧；亮暗状态都能区分。截图只能证明所见场景，不能证明全部交互。

本次完成标准是专项方案与独立素材备齐。尚未实施、尚未实机验收，不据此上调产品完成度。
