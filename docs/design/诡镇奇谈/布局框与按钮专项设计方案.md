# 诡镇奇谈 · 布局框与按钮专项设计方案

日期：2026-09-09。依据：用户本轮提供的五张截图，依次为导航、首页按钮、战役列表、成就列表、关于／支持页。

范围：只制定设计方案和素材要求。不生成图片，不修改应用代码，不接入运行时素材。此前牌桌效果图已停止等待，不作为本方案的依赖。

## 1. 核心判断

当前界面缺少商业作品应有的精细层级。问题不仅是颜色淡：所有内容都像同一种浅色圆角盒子，边界只有一根灰线，阴影几乎承担了全部立体感。大面积空白没有信息组织，按钮缺少触感，标题、状态、图标与操作的视觉重量没有分配。

本次采用「精装调查档案」的控件语言：墨绿漆面用于导航与主行动，象牙纸用于阅读，布面书脊用于分组，哑光黄铜只标出关键边界。克苏鲁气质通过古典排版、细密压印、档案编号和少量不安的图形体现；不把每个盒子包成祭坛。

精致感的来源按顺序是：比例 → 对齐 → 字体与字重 → 明暗层次 → 材质 → 装饰。每一级必须独立成立。去掉纹理后仍应是一套可读、有层级的界面。

## 3. 全局视觉基线

以下为设计尺寸，均使用 CSS 像素，不将截图物理像素直接当作界面尺寸。

| 项目 | 建议值／规则 |
| --- | --- |
| 页面底色 | 暖灰 #C9C4B7；仅保留极低对比纤维，去掉明显均匀点阵 |
| 阅读纸面 | #ECE6D8；内嵌纸面 #E0D8C9 |
| 导航／主按钮 | 墨绿 #203D39，高光 #35544C，暗边 #142825 |
| 正文与次文 | 深墨 #29312D；次文 #62675D，禁止整段低透明度 |
| 黄铜 | 默认 #93805A，高光 #C1AB79；只用于装饰和局部状态，不承担小字正文 |
| 危险色 | #97473F；非危险内容不使用大红图标 |
| 边界 | 主轮廓 1px；内高光 1px；内外边距 3–4px，仅用于重要组件 |
| 圆角 | 按钮 3px；卷宗卡 4px；小标签 2px；导航无整体圆角；避免大面积 10px 以上圆角 |
| 间距系统 | 4／8／12／16／24／32／48；同级间距保持一致 |
| 阴影 | 接触影短、软、近物体；只有浮层使用明显离地阴影；列表行无独立投影 |
| 装饰密度 | 每个大区域最多一个装饰焦点；角饰只用于外层，不嵌套使用 |

字体：中文标题优先有完整覆盖的宋体，英文标题配古典衬线；导航、按钮、正文使用清晰黑体。字体先复用已具备授权和覆盖能力的项目资源。不得为换字体让中文回落到默认字体，也不得把游戏符号字体用于正文。

页面标题 28–32px／600；区块标题 20–24px／600；卷宗标题 20–22px；按钮 15–16px／600；正文 15–16px／400，行高 1.65–1.8；辅助信息 12–13px／500。数字采用等宽数字。中文字距 0–0.04em，英文小型索引可用 0.08em；长英文名称不强制全大写或过大字距。

## 4. 导航：封面索引

桌面导航总高 60px。品牌区、主要页面、账户工具三组分别对齐。主要链接高 44px、左右内距 16px、组内间距 8px。整个导航使用暗漆面，上缘一根极弱高光，下缘一根黄铜细线与柔和接触影。

当前页采用暖白文字、底部 2px 黄铜短线与一个 4px 菱形端点；悬停只微亮底色，不等同当前页。赞助入口放在右侧工具组，小图标配文字，不抢占主要导航权重。外链保留外链提示。

窄屏放不下时收为菜单，不能压缩字号或截断“我的牌组”。菜单内当前项同样明确，触控热区至少 44px。图标只承担辅助含义，导航名称始终可见。

## 5. 按钮：可感知的材质和层级

主按钮的构造由五层组成：短接触影 → 深色外轮廓 → 上亮下暗的薄边 → 中央哑光漆面 → 清晰文字。高光只沿边缘，不在文字后制造反光斑。无需画粗厚金框。

| 按钮类型 | 材质与边界 | 尺寸与使用 |
| --- | --- | --- |
| 首页主行动“继续” | 墨绿漆面，暖白字，内侧细压线，轻黄铜顶边 | 高 48px，最小宽 120px，左右内距 24px |
| 次行动“加载游戏” | 象牙纸面，深墨字，细中性边，无与主按钮同等投影 | 与主按钮同高，间距 12px，不强求等宽 |
| 普通表单操作 | 轻纸面或暗实底，简化内边 | 高 40–44px，无角饰 |
| 图标工具 | 无独立重框，悬停时出现浅底 | 热区 44px，图标 18–20px，配可访问名称 |
| 危险确认 | 暗红边与明确操作动词 | 仅确认步骤强调，不能所有列表默认亮红 |
| 文字操作 | 有辨识度的文字与细下划线 | 用于取消、详情等次级动作 |

### 完整状态

默认：边缘清楚，文字对比稳定。悬停：漆面略亮，上缘高光增强，不改变尺寸。按下：位移最多 1px、阴影收短、内阴影增强。当前／切换选中：增加持续标识，不能仅停留在悬停色。键盘焦点：外围 2px 实线、外移 2px，与悬停可区分。禁用：减少材质明暗，文字仍清楚，不以整体 20% 透明度隐藏。处理中：保持宽度，显示进度符号与动词，按业务限制重复提交。错误：邻近显示原因与恢复动作，不把整颗按钮变成闪灯。

首页按钮允许内容变长到两行；不把“继续”和“加载游戏”烘焙进图片。减少动效模式取消按下位移，保留明暗反馈。

## 6. 战役卡：一份完整卷宗

桌面卷宗行目标高度约 132–156px，可随长标题增高。外纸面只有一层 4px 圆角边界，左侧 6–8px 布面书脊；书脊颜色低饱和，不直接代表游戏规则。

```text
┌─书脊─┬ 战役徽记  狂热之夜                      继续调查 → ┐
│      │           当前剧本 · 地底吞噬者                   │
│      │ 调查员头像＋姓名   单人／多人 · 标准模式      更多 ⋯ │
└──────┴──────────────────────────────────────────────────┘
```

战役徽记缩至 32–40px。标题占可伸缩主列，剧本与模式排在第二层。底行集合头像、人数、模式；不保留“两个头像占据整条宽空白”的结构。头像 36–40px，职业色只用 2px 边条而非厚彩框，提供姓名提示。

“继续调查”是明确入口。整卡点击如保留，不能吞掉更多菜单、头像详情或键盘操作。删除入口置于更多菜单并提供名称清楚的确认；触摸端菜单始终可达，不依赖悬停出现。

长英文战役名最多先显示两行，悬停／详情给完整名称；中文优先使用项目实际译名，不在设计稿中发明剧本名称。数据没有提供的日期、进度和编号不伪造为真实信息。没有数据时用明确的空状态文本，不补随机档案号。

700px 以下改为上下排列，主行动在下方，模式与人数换行；卡片之间间距 12–16px，不能靠缩小头像和字体硬塞一行。

## 7. 成就列表：索引册

将多个大圆角框收进一张连续纸面，只在外层保留细边和轻接触影。每个折叠标题行高 68–76px，上下内距 16px、左右 24px；行之间使用一根低对比短分隔线。取消标题行内部第二根大横线。

桌面列为：展开箭头 20px｜战役徽记 28px｜标题弹性列｜计数 64px｜进度 120px。计数和进度整体右对齐，不随标题长短移动。箭头使用统一矢量形态，展开旋转 90°。

零进度显示“0 / 14”及安静轨道，不能像禁用；部分完成用哑光黄铜填充；全完成加小型完成标记与文字。进度条高 4px，不发光、不使用巨大的绿色胶囊。

展开内容采用内嵌纸面或浅背景，成就条目独立列出名称、条件、状态。图标 20–24px；完成标志不是大贴纸。折叠与展开保持视线锚点。长列表继续保留按战役查找的能力。

小于 600px，计数与进度移到标题下方，箭头与标题保持一组。书名号规则统一：界面以战役名称为主，避免部分有《》、部分没有的视觉混乱；内容原文引用另行保留。

## 8. 关于／支持页：出版物式阅读

正文宽度约 720–820px，中文每行约 40–50 字；大屏可采用左侧窄目录＋右侧正文。标题不再占据巨大黑块：页面标题 30px，章节标题 22px，章节间距 32–40px，段落间距 12–16px。

支持区域保留唯一一块重点面板：薄纸面、左侧小型压印，说明后跟明确的“前往 Patreon”次级行动。版权声明、项目详情放在同一阅读流中，以章节标题和分隔线划分，去掉每段独立圆角与投影。

正文链接采用深青色＋下划线；已访问链接可用低饱和暗紫，但不出现浏览器默认亮蓝／亮紫。焦点时有清楚轮廓。项目名、版权持有人、作者和外链目的地址必须保留，不因美化改写法律事实。

截图里的“Arkham 恐惧: The 卡牌 Game”属于文本质量问题。后续内容修订应统一产品称谓为项目认可的“诡镇奇谈：卡牌版”，英文引用使用准确原名；此处仅记录设计要求，不在本轮修改文案数据或版权年份。

## 9. 其他布局框的统一规则

框体按用途分为四类：页面容器不画框；阅读纸面用单层浅边；操作面板使用内凹分区；浮层使用更强投影和明确标题区。禁止页面容器→卡片→内区三层都画同等粗细的框。

表单输入高 42–44px，轻内凹底色，边线比普通分隔线稍强；焦点、错误与只读明确区分。标签放在输入上方，帮助文字跟随其下。弹窗标题、正文、按钮分区靠间距与一条细线完成，不重复加纸框。

空状态使用短标题、说明和一个相关行动。可配小型印记，但不让大插画替代信息。加载状态保持原区域尺寸，减少布局跳动。提示框按信息、成功、警告、错误区分图标与文案，避免只换边框色。

## 10. 材质落地约束

优先由界面绘制轮廓、内高光、阴影、切角、布局、进度及所有文字。仅微纹理和少量原创压印需要美术素材，详见[素材要求](./布局框与按钮素材要求.md)。

重要边界采用可伸缩结构：固定角部、可延展边线、独立中心填充。任何包含四态或多枚徽章的大图，未经逐个裁切、统一安全区和尺寸验收，不作为可直接接入的 sprite。禁止把整张框图用非等比缩放硬铺满不同宽高的控件。

页面底纹、纸面纹理和控件纹理同时出现时，最多两层可被明显察觉。按最终 1× 尺寸验收，不以放大原图中看见很多细节作为完成标准。

## 11. 后续实施顺序与验收

P0：统一类型、尺寸、字体、边界与状态；先解决导航及两种按钮，再移除框体嵌套。P1：战役卡重排、成就表格对齐、阅读页限宽。P2：补纹理与压印，检查密度和动效。每步都用同一组截图对照，不靠素材数量判断效果。

验收矩阵：1440×900、1920×1080、390×844；100% 与 200% 缩放；中文及长英文；导航选中／展开；按钮默认／焦点／按下／禁用／处理中；战役零／一／多调查员；成就零进度／部分／完成／展开；关于页链接正常／访问／焦点。

通过标准：主行动三秒内可定位；标题、元信息、操作重量分明；进度列整齐；无拉伸花纹、文字截断、失去焦点和过长阅读行；普通正文与控件文字目标对比度至少 4.5:1；重要轮廓目标至少 3:1。数值是后续验收目标，此轮不声称已测量。
