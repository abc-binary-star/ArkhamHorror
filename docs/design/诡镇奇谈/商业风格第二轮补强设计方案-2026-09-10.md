# 诡镇奇谈 · 商业风格第二轮补强设计方案

版本：1.0 · 2026-09-10  
目标：把当前已经成立的「深海档案馆」视觉方向，从“有风格的 UI”推进到“核心操作区也像同一部精装克苏鲁桌游作品”。

## 1. 审查结论

当前公共壳层已经具备克苏鲁档案作品的识别度：深海灰绿、象牙纸、氧化黄铜和低对比纹理形成了稳定的品牌语言。主要差距集中在高频操作区，而不是封面或背景：牌桌工具栏仍混有旧紫色、粗边框、黑色半透明盒、过大圆角和霓虹揭示动效；新版行动托盘素材目前也被使用在顶部工具栏，实体语义尚未完全成立。

本轮不再增加触手、血眼、血迹或紫色霓虹等直白恐怖符号。克苏鲁感通过“深海压迫感、旧档案秩序、不可知的留白、氧化材质和危险状态印记”表达；商业感通过克制、可读、统一和可复用表达。

| 维度 | 当前 | 本轮目标 |
| --- | ---: | ---: |

## 2. 视觉收口原则

### 2.1 色彩

- 深海青绿承担主要操作和导航语义。
- 黄铜承担边线、焦点、编号、已选中和实体连接件语义。
- 氧化红只用于危险、错误和不可逆操作。
- 神秘紫仅保留给明确的神秘事件或职业语义，不再作为通用按钮、通用选中态或全局高亮。

### 2.2 形体

- 主要控件统一使用 3～6px 小圆角；卡牌和档案纸尽量保持硬边。
- 交互边框采用 1px 结构线、内线和小刻度，不使用 5px 彩色粗边。
- 按钮像压在牌桌上的铭牌，文本和图标始终由 HTML 渲染，不把文案烘焙进图片。
- 阴影只说明层级，不制造发光；高亮优先使用亮度、黄铜边线和轻微抬升。

### 2.3 氛围

- 牌桌中央保持低纹理和中明度，保证卡牌数字、地点名和调查员状态可读。
- 氛围集中在牌桌边缘、行动托盘、侧栏外框和弹窗遮罩。
- 揭示动效从“紫色霓虹”改为“短时暗幕 + 黄铜刻印 + 轻微雾化”，持续状态不闪烁。
- `prefers-reduced-motion` 下取消旋转、脉冲和持续辉光，只保留静态状态差异。

## 3. 核心布局调整

### 3.1 牌桌行动区

将行动托盘从顶部通用工具栏的视觉语义中分离出来：

1. 顶部 `.game-bar` 保留为轻量导航和系统操作，不使用宽幅托盘图作为主背景。
2. 牌桌底部新增或复用固定行动 dock，使用 `35-底部行动托盘-v2.png`，安全区预留给回合信息、结束回合和常用操作。
3. 行动按钮按宽度分为普通、宽型和图标型三类，不再把一张 3:1 铭牌强行拉伸到所有按钮。
4. 移动端行动 dock 贴合底部安全区，按钮最小触控尺寸不低于 42px。

### 3.2 弹窗与检定

- 继续使用 `29-故事抉择内框-v2.png`，降低叠加色层不透明度，保留纸面和黄铜角件。
- 正文、标题和选择区共用同一个纸面容器，不再嵌套无语义的黑色半透明盒。
- 主要选择使用深海青绿；危险选择使用氧化红；神秘选择可以使用低饱和紫，但必须有语义标签。
- 标题区固定，长文本只滚动正文区，底部操作区保持可见。

### 3.3 卡牌交互

- 默认卡牌不发光。
- 悬浮只抬升 2px 并显示轻微纸张阴影。
- 选中使用 `37-卡牌黄铜选中框-v2.png` 或 CSS 黄铜双线，不使用洋红色粗边。
- 拖拽使用窄黄铜插入线和纸张占位；禁用使用降饱和度和灰化，不使用黑色遮罩覆盖规则文本。

## 4. 本轮素材清单

| 文件 | 规格 | 用途 | 必须满足 |
| --- | ---: | --- | --- |
| `35-底部行动托盘-v2.png` | 3:1 | 牌桌底部固定行动 dock | 深海灰布、皮革底、窄黄铜压边；中央留白；无文字、无按钮 |
| `36-行动按钮四态铭牌组-v2.png` | 4:1 | 普通／悬浮／激活／禁用四态 | 四枚独立透明铭牌；每枚留出 HTML 文案安全区；状态差异克制 |
| `37-卡牌黄铜选中框-v2.png` | 4:5 | 卡牌选中、拖拽占位和焦点态 | 透明中心；四角黄铜结构件；无发光、无文字、无卡牌内容 |
| `38-调查揭示暗幕-v2.png` | 16:9 | 故事揭示、危险提示和短时转场 | 透明或极低不透明度边缘雾幕；深海青黑；不遮挡正文；无紫色霓虹 |

所有素材均为无文字底图，中文、本地化、键盘焦点和辅助技术信息由 DOM 与 CSS 提供。新素材先保存到设计目录，确认构图后再复制到运行时资源目录，不覆盖已有 `v2` 素材。

## 5. P0 实施顺序

1. 清理牌桌核心区的通用紫色按钮、5px 粗边框、15px 圆角、Arial 和持续紫色发光。
2. 将顶部 `.game-bar` 与底部行动 dock 拆成两种语义，避免托盘背景挂在顶部。
3. 将按钮按普通／宽型／图标型复用四态铭牌，不对图片做不成比例的拉伸。
4. 将卡牌选中态收敛为黄铜结构态，保留神秘紫在明确语义中的使用。
5. 为弹窗、行动 dock、卡牌和揭示状态补齐键盘焦点、禁用、长中文文案和 reduced-motion 规则。

## 6. 验收门槛

- 1440×900、1280×720、1024×768、390×844 四组视口下，牌桌主要信息不被行动 dock 遮挡。
- 顶部导航、底部操作、侧栏、弹窗和卡牌状态可以被辨认为同一套实体系统。
- 主要页面不再出现与主题冲突的通用紫色按钮；紫色出现时必须有神秘语义。
- 普通、悬浮、激活、选中、拖拽、禁用、等待和危险状态无需解释即可区分。
- 操作区没有持续闪烁或大面积霓虹；低动效模式下信息层级不丢失。
- 所有文字仍由 HTML 渲染，中文长文、键盘焦点和高缩放比例下保持可读。

本方案只涉及视觉、布局和交互状态表达，不改变游戏规则、API、存档结构和卡牌数据。
