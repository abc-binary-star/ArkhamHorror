# 诡镇奇谈 · 顶部导航栏专项设计方案

版本：1.0 · 2026-09-10  
范围：顶部公共导航栏的视觉、结构、状态、响应式和素材要求。本文先于代码接入与视觉验收，不改变路由、权限、文案含义、API 或游戏规则。

## 1. 目标与判断

顶部导航是玩家在每个页面都会反复看到的“封面书脊”，应承担品牌识别、当前所在位置和常用入口三件事。当前实现的问题不是缺少颜色，而是所有主链接被放进同一个大圆角框，并以青绿色胶囊表达当前页；品牌、页面导航和账户工具没有形成清楚的重量层级。赞助内容与“关于”页是同一页面，因此不再作为独立导航入口。

本次目标是把导航从“后台工具栏”提升为“精装调查档案的封面索引”：古旧辉煌，但不堆砌触手、血迹、眼睛或霓虹；典雅精致，但不牺牲中文可读性和点击效率。

## 2. 核心概念：封面索引

导航由三层构成：

1. **深海漆面底板**：墨绿灰黑的连续底色，带极低对比的布面／漆面微纹理；顶部一条弱高光，底部一条细黄铜压线。
2. **品牌书脊**：左侧徽记、中文名称和英文副标组成固定入口；不再做成独立胶囊，像封面上的烫印题签。
3. **索引刻度**：主要链接以平静的文字排布呈现，当前项用暖白文字、底部黄铜短线和一个小菱形端点标记；悬停只略微提亮，不伪装成当前页。

视觉气质来自比例、排版、压印和材质顺序，而不是装饰数量。去掉纹理后，导航仍应是一套清楚、稳重、有层级的界面。

## 3. 信息层级与布局

桌面导航目标高度为 **60px**，允许在 52–64px 范围内随品牌锁定区微调。

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│  徽记 诡镇奇谈        我的牌组  牌库  成就  关于              用户⌄        │
│  ─────────品牌书脊────  ───────────主要索引──────────  ─────账户工具─────  │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 3.1 品牌区

- 宽度约 190–220px；徽记 34–38px，中文名 17–19px，英文副标 8–9px。
- 品牌入口保留现有 `/assets/veiled-harbour/06-诡镇奇谈徽记.svg`，因为它是项目已有的矢量品牌资产，不用生成新的替代 Logo。
- 中文标题使用项目已有 Arno／完整中文覆盖字体；英文副标作为小型索引，不提高对比度到和中文同级。
- 品牌区右侧用一条很细的黄铜竖向分隔线或短刻度与主导航区连接，不能形成第二个框。

### 3.2 主导航区

- 当前实现中的 `.main-links` 外部圆角托盘取消，主链接回到连续排版。
- 主要链接热区高度不低于 44px，左右内距 14–18px，组内间距 4–8px。
- 推荐顺序继续沿用当前产品入口：我的牌组、牌库／卡牌、成就、关于；牌组构建器若存在则作为工具入口处理。赞助内容只从“关于”页进入。
- 文字不全大写、不压缩字距；中文导航 15–16px／600，辅助英文 11–12px／500。
- 主要索引区可横向滚动，但滚动条隐藏；滚动不能改变单项热区高度。

### 3.3 工具区

- Patreon／赞助不作为独立导航项出现；它属于“关于”页内部的支持项目内容，避免同一页面在顶部重复占位。
- 用户名、设置、退出保持右侧；用户名显示为窄档案标签，展开菜单使用象牙档案纸面。
- 管理员入口不在普通用户视线中抢占主导航权重；仍保留现有权限判断。

## 4. 视觉规范

| 项目 | 规范 |
| --- | --- |
| 底色 | `#26373A`～`#303A3D` 深海灰绿；纹理对比度不超过 8% |
| 顶部高光 | 1px，暖灰白透明度约 12–18% |
| 底部压线 | 1px 黄铜 `#9B7D45`，下方可有 2–4px 接触阴影 |
| 默认文字 | `#C7CFCC`，保证与底板的阅读对比 |
| 当前文字 | `#F4EFE4`，加底部黄铜短线与小菱形端点 |
| 悬停 | 仅改变文字亮度和极低对比底色，不改变布局尺寸 |
| 圆角 | 导航整体不使用圆角；小型账户标签最多 3–4px |
| 阴影 | 只表现导航与页面的接触关系，不做发光 |
| 装饰密度 | 左右各一个焦点：品牌徽记与右侧工具分隔；中间保持留白 |

## 5. 交互状态

### 默认

链接处于安静的灰绿文字状态；不画独立卡片，不出现紫色或持续发光。每一项仍有清楚的 44px 以上点击热区。

### 悬停

文字向暖白提亮，底部可出现 1px 暗黄铜短线；不使用当前页的完整高亮。鼠标移走后迅速恢复，动效 120–160ms。

### 当前页

使用暖白文字、底部 2px 黄铜短线和 4px 菱形端点，短线宽度约为文字宽度的 55–70%。当前页不使用大面积青绿色背景，以免每个页面都像被贴上彩色按钮。

### 键盘焦点

使用外围 2px 实线焦点环并向外偏移 2px；焦点环颜色为亮黄铜或浅青绿，不能只依赖底部线。焦点不改变元素尺寸，不被 `overflow-x: auto` 裁掉。

### 下拉菜单

用户菜单沿用象牙档案纸语义：单层纸面、细边、近物阴影；打开按钮仅加黄铜边线。菜单项热区不低于 44px，退出使用氧化红文字或左侧小刻度，而不是整行红底。

### 禁用与窄宽

若某个入口因权限不显示，不保留空槽位。入口过多时优先隐藏次级工具并放进移动菜单，不缩小中文字号、不截断“我的牌组”。

## 6. 响应式构图

### 1440px 及以上

品牌区、主导航、工具区同一行；主导航占据弹性空间，工具区固定在右侧。页面左右留 20–32px 安全边距，品牌徽记不贴边。

### 769–1199px

品牌副标可隐藏，主导航保持文字显示；牌组构建器和管理员可降级为工具区或更多菜单。当前项标记仍必须可见。

### 768px 以下

采用独立移动构图：左侧汉堡按钮，中间品牌徽记／中文名，右侧账户入口；主链接全部进入象牙档案纸下拉菜单。菜单项保持至少 44px 高，当前项继续使用黄铜短线与菱形。

移动菜单不直接复用桌面横向托盘的背景图，避免裁切纹理导致像一条被拉长的横幅。

## 7. 素材方案

文字、路由名称、外链提示、当前态和焦点态全部由 HTML／CSS 渲染。位图只承担不易用 CSS 表达的微纹理与压印。

| 文件 | 规格 | 用途 | 约束 |
| --- | ---: | --- | --- |
| `39-顶部导航漆面底板-v1.png` | 3:1，建议 1536×512 | 桌面导航底板的纹理／边缘层 | 深海墨绿、旧漆面、极低对比；不含文字、Logo、按钮；中心留白 |
| `40-导航黄铜索引压印-v1.png` | 1:1，建议 512×512，透明背景 | 品牌分隔、当前项或菜单标题的小型压印 | 抽象天文刻度／海图罗盘；无文字；不替代现有 Logo；不发光 |

`39` 只应作为背景层使用，不能把导航边框、链接状态和文案烘焙进图中；`40` 只作为低频装饰，桌面每个导航栏最多使用 1–2 次。生产接入前导出 WebP，并在 1× 真实尺寸检查纹理是否喧宾夺主。

## 8. 接入顺序与验收

1. 先改 `.main-links` 与 `.nav-link` 的结构语义：取消整体胶囊，建立当前项短线／菱形和焦点环。
2. 再接入 `39` 的漆面微纹理与底部黄铜压线；保留 CSS 纯色作为加载失败回退。
3. 接入 `40` 前先确认品牌徽记、分隔线和当前项已经成立；若装饰让信息层级变差，则不接入或降低透明度。
4. 最后处理移动菜单和用户下拉菜单，确保桌面与移动端是同一套材质语言但不是同一张图硬裁切。

验收视口：1440×900、1280×720、1024×768、390×844；状态：默认、悬停、当前、键盘焦点、用户菜单展开、长中文、长英文、未登录、管理员入口存在／不存在。

通过标准：

- 玩家在 1 秒内能识别品牌、当前页面和主要入口。
- 导航不再出现“所有入口都是同等重量的彩色胶囊”。
- 当前态不依赖颜色，色盲或低饱和显示下仍能通过文字与黄铜结构识别。
- 文字由 DOM 渲染，中文、本地化、键盘焦点和辅助技术信息不受素材影响。
- 纹理关闭后布局仍成立；开启后不干扰长文字、下拉菜单和移动触控。

本阶段交付：设计方案与两项待生成视觉素材。代码接入和真实视口验收另列任务，不在本方案中宣称完成。
