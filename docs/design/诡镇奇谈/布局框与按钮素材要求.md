# 诡镇奇谈 · 布局框与按钮素材要求

日期：2026-09-09。配套文档：[布局框与按钮专项设计方案](./布局框与按钮专项设计方案.md)。本轮已生成并接入 C01–C03，C04–C06 以透明 SVG 补齐；本文件同步记录实际交付。

## 1. 制作原则

美术只负责材料表面与少量装饰，界面负责文字、数字、轮廓、交互与自适应。先完成无纹理的组件排版，再根据需要使用以下素材。不得把控件状态、进度数值、品牌文字、版权文案、战役名称做进位图。

所有素材属于「诡镇奇谈」同一设计语言。哑光、细颗粒、低对比、克制磨损；黄铜不镜面反光；纸张不满是污渍；不得加入海港字样、未经确认的徽章或伪造规则符号。

## 3. 不需制作的图片

- 不制作完整导航条图片：宽度、语言、当前页随视口变化。
- 不制作带文字的按钮图片或四态大拼图：统一组件用同一纹理配合状态绘制。
- 不制作完整战役卡边框：角件与边线拆分，正文决定高度。
- 不制作成就进度条和完成数图片：必须反映实时数据。
- 不重画战役标志、调查员头像、职业符号：优先复用现有准确资源。
- 不为每段关于页文本制作纸板：一张低对比纸材质足够。

## 4. 分层与导出交付

每项交付可编辑源文件、运行候选文件、1×／2×预览及清单。位图原稿保留PNG或分层源；运行候选优先WebP；透明装饰优先SVG。预览同时展示浅纸、暗绿、纯灰三种底色，防止透明边缘发白或发黑。

无缝材质不带外围留白；透明装饰不带伪棋盘格或白色背景。图形边缘预留约2px抗锯齿空间，并记录实际内容边界。若后续确需九宫格边框，要附上上／右／下／左切片尺寸、最小使用尺寸、角部锁定规则和内容安全区，不能只交一张PNG。

建议体积预算：单张微纹理不超过80KB；单个SVG角件／工具图标不超过10KB；新增控件材质首屏总量不超过250KB。均为交付目标，若压缩导致条带、糊边或纸面脏污，应先降低纹理复杂度，不牺牲可读性。

清单字段：编号、版本、用途、源文件、运行候选文件、尺寸、内容边界、色彩模式、是否透明、是否可平铺、推荐显示尺寸、禁用用法、文件大小、SHA-256、制作来源／授权说明。仅记录素材来源，不推断既有游戏图像权利。

## 5. 生图提示词与实际执行记录

C01：正视、无缝、均匀照明的1920年代深墨绿哑光漆面微纹理；极细颗粒、低对比、边缘连续；没有控件、边框、字母、金属角饰、镜面亮斑、物件、logo、水印。

C02：正视、无缝、均匀照明的象牙棉纤维档案纸微纹理；整体洁净、纤维柔和、色差极小；没有文字、符号、线格、折痕、污渍、纸张外边缘、撕裂、logo、水印。

C03：正视、无缝、均匀照明的深墨绿精装书布微纹理；细密织物、低反光、缩小后均匀；没有书本物体、接缝、书脊文字、花纹、徽记、明暗渐变、logo、水印。

素材生成后需要检查2×2平铺接缝与最终显示尺度，接缝不合格则不标记为可平铺。C04–C06不使用上述位图提示词，依据组件几何规范制作或复用。

## 6. 验收与停止标准

在48px主按钮、44px次按钮、60px导航、132–156px卷宗卡、72px成就行和限宽正文中分别验收。纹理不能遮文字；装饰不能改变按钮状态含义；跨尺寸不拉伸；手机高像素密度下不发虚；光照方向一致；禁用状态仍可读。

若加材质后主行动更难辨认、文字更脏、边框更拥挤，则降低或移除材质。完成标准是组件更清楚、更有触感，而非每个组件都用上所有素材。
