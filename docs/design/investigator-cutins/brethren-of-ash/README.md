## 展示方式

- **技能发动：中央长条，1000ms。** 桌面宽度约 920px、高度约 190px，窄屏相应缩小。牌桌保持可见；不加全屏遮罩，不打断操作。横条从侧面掠入，人物短促推近，光线沿一个方向扫过后退出。只显示小号姓名与“技能发动”，无巨大技能口号。图片加载后才起计时。
- **旧印：大屏一闪，1600ms。** 专属人物特写在画面中心迅速展开，暖金光与职业色照亮脸和道具，随后干净淡出。文案为“旧印”，避免在尚未确定结果时显示“检定成功”。旧印不等于自动成功。
- **自动失败：大屏一闪，1600ms。** 与旧印沿用镜头、道具和背景，亮光转为裂散的暗红与冷灰，画面短促回缩后淡出；不用持续抖动、频闪或搞笑表情。文案为“自动失败”。不暗示角色死亡、装备损毁或额外伤害。
- 遵循“额外动画”、剧本覆盖设置和系统减少动态效果。减少动态效果时取消位移、缩放和扫光，只作静态短暂展示。
- 技能特写不抢焦点、不阻塞游戏操作。旧印／失败不抢焦点；接入时与混沌标记揭示及结果展示协调。两种大屏状态互斥，一次检定只呈现一个已生效的标记状态。

## 接入时的触发约束

设计触发点基于 backend/arkham-api/library/Arkham/Investigator/Cards 中的五个实际实现，不套用旧版同名调查员：

- **丹妮拉·雷耶斯**：同地点调查员被敌人攻击后，接受丹妮拉的角色响应并开始反击时。
- **乔·戴蒙德**：成功调查后，角色响应实际抽牌时。
- **崔西·斯卡伯勒**：实际消耗她提供的额外闪避行动并开始闪避时；普通闪避不播。
- **德克斯特·德雷克**：打出资产后，接受角色响应并完成“返回资产／打出另一资产”的选择时。
- **伊莎贝尔·巴恩斯**：确认支付 1 点直接恐惧，并从弃牌堆投入合法技能牌时。

角色技能需由服务端确认发动，不能因按钮出现、鼠标悬停、打开卡牌或接受选择前就播放。多人牌桌按实体与能力事件去重，首次载入、重连及 Undo 建立基线，不重播旧事件。

旧印与自动失败按用户确认的 **ElderSign / AutoFail** 标记标准设计。应等待标记成为最终有效标记再播放：被取消、忽略或重抽的标记不播；若一个检定同时存在有效旧印与自动失败，以生效的自动失败呈现为优先。不以最终成功／失败差值触发。旧印仍可导致检定失败；乔和伊莎贝尔的额外收益还需要最终成功，所以画面只表达旧印意象，不提前声称收益已发生。
